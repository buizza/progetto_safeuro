# progetto_safeuro
# Nome del Progetto

## Descrizione
Il sistema permette agli utenti di consultare offerte geolocalizzate, con la possibilità di filtrarle tramite ricerca dinamica in base ai propri interessi.

## Attori
Il diagramma dei casi d'uso individua tre attori principali:

- **Utente non registrato**: utente che accede al sistema senza aver effettuato l'autenticazione.
- **Utente registrato**: utente che ha effettuato il login e usufruisce delle funzionalità del sistema.
- **GPS**: sistema esterno che fornisce la posizione dell'utente e la posizione delle offerte.

## Funzionalità principali

### 1. Login
Gli utenti possono autenticarsi per accedere come utenti registrati.

### 2. Visualizzazione delle offerte
Gli utenti possono consultare le offerte disponibili, mostrate in base alla posizione fornita dal GPS.

### 3. Ricerca dinamica
Durante la visualizzazione delle offerte è possibile effettuare una ricerca dinamica, per filtrare i risultati e trovare solo ciò che interessa realmente.
